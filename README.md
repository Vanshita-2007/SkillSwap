# SkillSwap - No Cash. Just Credits.

Tagline: Trade what you know. Learn what you lack.

Devfolio track: AI + Community + Education

## Problem
Campus talent stays hidden. Students pay outside for skills peers hold for free. No trust system exists for peer learning.

## Solution
Post skill. Earn credits. Spend credits to learn. AI match ranks best tutor in seconds. Chat, meet, proof, rate. Credits move. Cash stays out.

## Live Demo - 60 Sec
1. Enter name + college email. Hit Enter.
2. Post a skill. See it live in feed.
3. Search guitar. Hit AI Match. Top 3 picks appear.
4. Book one. Open booking. Send hi in chat.
5. Hit Upload Proof. Hit Complete + Rate. Credits move. Rating updates.

## Features
- College login mock, local only
- Post skill with credit rate
- Live feed + search
- AI match mock with keyword + rating score
- Book + in-app chat mock with auto-reply
- Proof upload entry
- Complete + rating with credit transfer
- Leaderboard by sessions
- Reset demo data in one click

## Tech Stack
- HTML5
- CSS3, pure CSS
- Vanilla JS, zero dependency
- localStorage for user, skills, bookings, chat

## How To Run
1. Extract zip.
2. Double-click `index.html`.
3. Optional serve: `python -m http.server` then open localhost.
4. No install. No backend. Works offline after first open.
